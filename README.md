# F1 2026 Prediction System

This project predicts the 2026 Formula 1 season using a hybrid approach:

- qualifying prediction model
- Monte Carlo race simulation
- projected driver standings
- projected constructor standings
- race-by-race probability outputs

It combines:
- historical race data
- 2026 testing and session data
- custom 2026 priors for drivers, teams, engines, tracks, upgrades, and reliability

- `data_loader.py`

## Main outputs

The system produces:

- qualifying predictions for every round
- race summaries for every round
- full race probability tables
- projected driver championship standings
- projected constructor championship standings
- expected points by race

## Required data

The project expects these categories of data:

### Historical data
A cleaned historical master dataset, such as:

- `model_ready_combined_2009_2025.csv`

### Priors
These CSV files are used as 2026 baseline assumptions:

- `driver_priors_2026.csv`
- `team_priors_2026.csv`
- `engine_priors_2026.csv`
- `track_priors_2026.csv`
- `reliability_priors_2026.csv`
- `upgrade_priors_2026.csv`
- `team_engine_map_2026.csv`
- `driver_team_map_2026.csv`

### 2026 data
Cleaned 2026 session data, such as:

- pre-season testing
- Australian Grand Prix
- Chinese Grand Prix
- practice and qualifying lap data
- weather files

## Installation

Create a Python environment, then install dependencies:

```bash
pip install -r requirements.txt
```

## Running from the command line

Run the full project:

```bash
python main.py
```

Run a single round:

```bash
python main.py --race 3
```

Run fewer simulations for faster testing:

```bash
python main.py --sims 1000
```

Save outputs to CSV:

```bash
python main.py --save
```

## Modeling approach

### Qualifying
The qualifying model uses:

- 2026 pace signal as the main input
- priors as strong baseline features
- historical data for interaction patterns

### Race simulation
Each race simulation includes:

- qualifying grid position
- driver pace
- team pace
- engine influence
- reliability
- weather impact
- tyre stress
- safety car randomness
- upgrade effects

### Standings
Championship standings are computed from expected points generated by the race simulations.

## Important notes

- The 2026 season is treated differently because of the regulation reset.
- Historical team pace is not trusted as much as 2026 data and priors.
- Driver skill is more transferable than team performance.
- If you change the priors, rerun the full simulation pipeline.
